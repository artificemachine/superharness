# ADR-0001: Record architecture decisions

## Status
Accepted.

## Context
Architecture choices need durable context so future contributors can understand why the
project took a particular direction.

## Decision
Record material architecture decisions as numbered ADRs in `docs/adr/` before implementation.

## Consequences
This satisfies the Decisions before code doctrine rule. ADRs add a small documentation step
and preserve the reasoning needed to revisit a decision responsibly.
